# System Design Examples

This directory contains complete implementations of real-world system designs demonstrating Low-Level Design principles.

## Available Examples

### 1. Parking Lot System
A comprehensive parking lot management system demonstrating:
- Multiple vehicle types (Car, Bike, Truck)
- Different parking spot sizes
- Entry/Exit management
- Payment processing
- Availability tracking

**Patterns Used:**
- Factory Pattern (Vehicle creation)
- Singleton Pattern (Parking lot instance)
- Strategy Pattern (Pricing strategies)

### 2. Library Management System
A library management system featuring:
- Book inventory management
- Member management
- Book borrowing and returning
- Fine calculation
- Search functionality

**Patterns Used:**
- Observer Pattern (Notification system)
- Factory Pattern (User creation)
- Strategy Pattern (Fine calculation)

## Learning Approach

Each system design example includes:

1. **Requirements Document** - Clear problem statement
2. **Class Diagram** - Visual representation of classes and relationships
3. **Implementation** - Complete Java code
4. **Design Patterns** - Patterns used and why
5. **Test Cases** - Example usage scenarios

## How to Study

1. Read the requirements first
2. Try to design the system yourself
3. Compare with the provided solution
4. Understand the design patterns used
5. Run and modify the code
6. Think about possible improvements
